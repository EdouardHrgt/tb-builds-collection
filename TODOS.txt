## 1. Friends / Follow System

- When viewing another user's build, clicking on their profile should open their profile page, displaying:
  - All builds published by that user.
  - A **Follow** button to follow/unfollow them (an animation on the button to see clearly the action of following somebody).

- On their own profile page, users can see a list of all the people they follow. This information should be private and only visible to the account owner.

- Display the number of followers on each user's profile.
  - This information could be public by default.
  - Users should have the option to hide their follower count through their privacy settings.
  - Make sure the code allows this visibility setting to be implemented.

- When a followed user publishes a new build, it should appear on the main Build List page in a dedicated section: **Latest Builds from Followed Users**.
  - Only display the latest build from each followed user.
  - Consider using either a horizontal carousel or pagination to browse the builds.

## 2. Weapon & Equipment Rules

- Grail Knight, Slayer and Warrior Priest do not have access to ranged weapons. Instead, they can equip a second melee weapon.
  - Both melee weapon slots can contain the same weapon.
  - Each weapon slot has its own independent traits and properties.

- Some weapons do not have access to certain traits:
  - Scrounger and Conservative Shooter are not available on Sienna's staves, Moonfire Bow or Trollhammer Torpedo.
  - Heat Sink and Thermal Equalizer are exclusive to Sienna's staves.
